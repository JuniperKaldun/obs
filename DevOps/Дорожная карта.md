# Дорожная карта

> [!info] Как пользоваться
> Чекбоксы отмечаются, когда пункт получается **без подсказок**. Месяц не закрыт, пока не собран артефакт.

## Обзор

| Месяц | Тема | Артефакт |
|---|---|---|
| 1 | Терминал и Linux | Свой VPS, SSH-ключи, команды без подглядывания |
| 2 | Linux глубже + сети | Nginx, TLS, firewall, бэкапы |
| 3 | Git + bash | Репозиторий с конфигами, 5–7 скриптов |
| 4 | Python | Скрипт, решающий реальную задачу |
| 5 | Docker | Приложение в контейнере, образ < 200 МБ |
| 6 | Compose + вход в CI | Compose-стек: приложение + БД + proxy |
| 7 | CI/CD | Пайплайн: тесты → сборка → пуш → деплой |
| 8 | Облако + Terraform | Сеть и ВМ из кода |
| 9 | Terraform + Ansible | Инфраструктура с нуля одной командой |
| 10 | Kubernetes: база | Приложение в кластере |
| 11 | Kubernetes: Helm | Helm-чарт, TLS, разбор поломок |
| 12 | Наблюдаемость | Дашборд, алерты, runbook |
| 13 | GitOps + безопасность | ArgoCD, Trivy, секреты |
| 14 | Портфолио | 2–3 проекта, мок-интервью |

---

## Месяц 1 — Терминал и Linux

- [ ] Файлы, права, процессы, пакеты, systemd, логи
- [ ] Поднять VPS, отдельный пользователь, вход только по SSH-ключам
- [ ] `ufw`: открыты только нужные порты
- [ ] Конспект команд, которые пришлось гуглить

**Артефакт:** сервер, куда захожу по ключу и свободно ориентируюсь в файловой системе.

## Месяц 2 — Linux глубже и сети

- [ ] IP, DNS, HTTP/HTTPS, порты, NAT — «что происходит от браузера до приложения»
- [ ] Nginx на VPS + TLS-сертификат (Let's Encrypt)
- [ ] Бэкап по cron + проверка, что он восстанавливается
- [ ] `dig`, `curl`, `ss`, `tcpdump` в базовых сценариях

**Артефакт:** сайт по HTTPS за nginx, рабочие бэкапы, закрытый firewall.

## Месяц 3 — Git и bash

- [ ] Git: ветки, merge/rebase, конфликты, PR, теги
- [ ] Bash: переменные, условия, циклы, пайпы, `set -euo pipefail`
- [ ] 5–7 скриптов: бэкап, проверка диска, ротация логов
- [ ] Репозиторий с конфигами и dotfiles

**Артефакт:** репозиторий, который разворачивает мои конфиги на новой машине.

## Месяц 4 — Python

- [ ] Типы, структуры данных, функции, исключения, модули
- [ ] `requests`, `json`, `yaml`, `argparse`, `subprocess`
- [ ] Скрипт: метрики сервера → Telegram/API
- [ ] Прочитать чужой скрипт на 100+ строк и объяснить его

**Артефакт:** утилита, которой пользуюсь сам, а не учебная задача.

## Месяц 5 — Docker

- [ ] Образы и слои, Dockerfile, multi-stage, `.dockerignore`
- [ ] Непривилегированный пользователь в контейнере
- [ ] Сети Docker, volumes
- [ ] Образ своего приложения меньше 200 МБ

**Артефакт:** приложение запускается контейнером одной командой.

## Месяц 6 — Compose и первый CI

- [ ] Compose: приложение + БД + reverse proxy
- [ ] Переменные окружения и секреты в compose
- [ ] Первый пайплайн сборки образа (GitLab CI или GitHub Actions)

**Артефакт:** `docker compose up` поднимает весь стек.

## Месяц 7 — CI/CD

- [ ] Пайплайн: линтеры → тесты → сборка → скан → пуш → деплой
- [ ] Кэш, артефакты, окружения
- [ ] Секреты не в репозитории
- [ ] Пайплайн падает и **не** деплоит при ошибке

**Артефакт:** деплой по кнопке, руками на сервер не захожу.

## Месяц 8 — Облако и Terraform

- [ ] VPC, подсети, security groups, IAM, ВМ, балансировщик
- [ ] Terraform: провайдер, ресурсы, state
- [ ] Remote backend и блокировка state
- [ ] Сеть и ВМ создаются из кода

**Артефакт:** `terraform apply` поднимает окружение с нуля.

## Месяц 9 — Terraform глубже и Ansible

- [ ] Terraform: модули, `import`, lifecycle
- [ ] Ansible: inventory, playbook, роли, идемпотентность, vault
- [ ] Инфраструктура разворачивается одной командой
- [ ] Удалить всё и развернуть заново

**Артефакт:** воспроизводимое окружение без ручных шагов.

## Месяц 10 — Kubernetes: база

- [ ] Pod, Deployment, Service, ConfigMap/Secret, Namespace
- [ ] Локальный кластер k3d или kind
- [ ] Приложение в кластере, доступ через ingress
- [ ] `kubectl describe/logs/events` при поломке

**Артефакт:** приложение живёт в кластере и обновляется без простоя.

## Месяц 11 — Kubernetes: Helm и диагностика

- [ ] Helm: чарт, values, шаблоны
- [ ] Probes, requests/limits, rolling update, HPA
- [ ] TLS через cert-manager
- [ ] Разобрать 5 сломанных сценариев: CrashLoopBackOff, Pending, ImagePullBackOff и другие

**Артефакт:** Helm-чарт + умение чинить кластер по симптомам.

## Месяц 12 — Наблюдаемость

- [ ] Prometheus: метрики, PromQL, exporters
- [ ] Grafana: дашборд для своего приложения
- [ ] Логи: Loki или ELK
- [ ] 3–5 осмысленных алертов + runbook на страницу
- [ ] Уронить сервис и починить по своему runbook

**Артефакт:** вижу состояние сервиса и знаю, что делать при аварии.

## Месяц 13 — GitOps и безопасность

- [ ] ArgoCD: состояние кластера = репозиторий
- [ ] Trivy в пайплайне, блокировка при critical
- [ ] Секреты: Vault, SOPS или Sealed Secrets
- [ ] RBAC и service accounts, наименьшие привилегии

**Артефакт:** деплой только через Git, уязвимые образы не проходят.

## Месяц 14 — Портфолио и собеседования

- [ ] README и схема для сквозного проекта
- [ ] 2–3 проекта в портфолио
- [ ] 40 минут рассказа о своих решениях
- [ ] Мок-интервью: Linux, сети, troubleshooting K8s, Terraform, CI/CD
- [ ] Резюме и первые отклики

**Артефакт:** могу объяснить каждое решение в своих проектах и почему альтернативы хуже.

## Смежная работа

Чистых junior DevOps с нуля берут мало. Параллельно с планом имеет смысл смотреть на входные роли: системный администратор, NOC/дежурный, инженер техподдержки инфраструктуры, junior SRE. Год такой работы даёт production-опыт, после которого переход в DevOps реалистичнее.
