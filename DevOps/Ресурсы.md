# Ресурсы

> [!tip] Минимум, без коллекционирования
> Берите один источник на тему. Второй — только если первый не объясняет.

## Linux

- [The Linux Command Line](https://linuxcommand.org/tlcl.php) — Уильям Шоттс, бесплатно. Основной учебник первого месяца.
- Свой VPS — главный тренажёр. Без него прогресса не будет.
- `man`, `--help` и `journalctl` — привычка, а не статья.

## Сети

- [Practical Networking](https://www.practicalnetworking.net/) — понятные объяснения без академичности.
- Документация по TCP/IP — по мере вопросов, не подряд.

## Git

- [Pro Git, русская версия](https://git-scm.com/book/ru/v2) — бесплатно.

## Python

- [Официальная документация](https://docs.python.org/3/) и [Python для начинающих](https://docs.python.org/3/tutorial/).
- Практика важнее синтаксиса: сразу скрипт под свою задачу.

## Docker

- [Документация Docker](https://docs.docker.com/) — раздел Get started.
- «Docker Deep Dive», Найджел Поултон — если нужен структурированный текст.

## Kubernetes

- [Документация Kubernetes](https://kubernetes.io/docs/home/).
- [Killercoda](https://killercoda.com/) — интерактивные лаборатории в браузере, без своего кластера.
- «Kubernetes Up & Running» — для общей картины.
- Для сертификации CKA: курс и [killer.sh](https://killer.sh/) — только после месяца 11.

## Terraform

- [Tutorials HashiCorp](https://developer.hashicorp.com/terraform/tutorials).
- Документация провайдера того облака, которое выбрали.

## Ansible

- «Ansible for DevOps», Джефф Гирлинг — [ansiblefordevops.com](https://www.ansiblefordevops.com/).

## Надёжность и мониторинг

- [Google SRE Book](https://sre.google/sre-book/table-of-contents/) — бесплатно, читать выборочно.
- [Документация Prometheus](https://prometheus.io/docs/introduction/overview/).

## Видео

- TechWorld with Nana — хороший вход в Docker/K8s, но не заменяет лаборатории.

## Прочее

- Английский: читать документацию без переводчика — отдельный навык, тренируется ежедневно по 10 минут.
- [[Журнал прогресса]] — важнее любого курса.
