# Синхронизация хранилища

Репозиторий — единственный источник правды. Оба устройства делают `pull` перед работой и `push` после.

| Устройство | ОС | Путь к хранилищу |
|---|---|---|
| Основной ПК | Windows 11 | `E:\OBSIDIAN\obs` |
| Ноутбук | Ubuntu 24.04 | `~/obs` |

Репозиторий: `git@github.com:JuniperKaldun/obs.git`, ветка `main`. Первый коммит: «vault: начальное состояние».

## Что попадает в репозиторий

- Все заметки `*.md`
- `.obsidian/` — настройки и плагины, чтобы вид был одинаковым на обоих устройствах

Исключено через `.gitignore`:

- `.obsidian/workspace.json` — раскладка окон, у каждого устройства своя
- `.trash/` — корзина Obsidian
- служебный мусор ОС: `Thumbs.db`, `desktop.ini`, `.DS_Store`

Файл `.gitattributes` задаёт `eol=lf`, чтобы Windows и Linux не воевали из-за переводов строк.

## Ежедневный цикл

1. Открыл Obsidian — плагин Obsidian Git делает `pull`.
2. Работаешь, правишь заметки.
3. Закрыл Obsidian — изменения уходят в `commit` и `push`.

Вручную то же самое:

```bash
cd ~/obs
git pull --rebase
git add -A
git commit -m "сессия: права доступа"
git push
```

## Правила

> [!warning] Одна машина за раз
> Не редактируй одну и ту же заметку на двух устройствах одновременно. Перед переключением дождись, пока изменения уйдут в репозиторий.

- Коммит — после каждой сессии, а не раз в неделю. История должна отражать прогресс.
- Конфликт: `git pull --rebase`, открыть файл, оставить нужный вариант, `git add файл`, `git rebase --continue`.
- Если сомневаешься — `git status` и `git log --oneline`. Эти две команды объясняют почти всё.

## Установка на ноутбуке

```bash
sudo apt update && sudo apt install -y git
git clone <адрес-репозитория> ~/obs
```

Obsidian: AppImage с [obsidian.md/download](https://obsidian.md/download) или `flatpak install flathub md.obsidian.Obsidian`. Открыть `~/obs` как хранилище.

Затем на обоих устройствах: Settings → Community plugins → **Obsidian Git** → Auto pull interval 5–10 мин, Auto commit-and-sync 10 мин, Pull on startup — включить.

## Проверка

```bash
git check-ignore -v .obsidian/workspace.json   # покажет, каким правилом исключён
git status --ignored                           # что вообще игнорируется
git log --oneline --stat -1                    # что вошло в последний коммит
```
