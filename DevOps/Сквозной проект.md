# Сквозной проект

Один проект, который растёт вместе с навыками. Вместо десяти учебных поделок — одна история, которую можно рассказать на собеседовании: «вот как я это строил и почему именно так».

**Идея:** небольшой сервис (свой или open-source), который последовательно проходит путь от «работает на VPS» до «GitOps в Kubernetes с мониторингом».

| Этап | Месяц | Что появляется | Готово, когда |
|---|---|---|---|
| 1 | 2 | Приложение на VPS за nginx с TLS | Открывается по HTTPS, бэкапы идут |
| 2 | 5 | Приложение упаковано в Docker | Образ собран, запуск одной командой |
| 3 | 6 | Compose-стек | Приложение + БД + proxy поднимаются вместе |
| 4 | 7 | CI/CD | Деплой по кнопке, руками ничего не делаю |
| 5 | 9 | Terraform + Ansible | Инфраструктура с нуля из кода |
| 6 | 10–11 | Kubernetes + Helm | Приложение в кластере, обновление без простоя |
| 7 | 12 | Мониторинг | Дашборд, алерты, runbook |
| 8 | 13 | GitOps | ArgoCD синхронизирует кластер из Git |
