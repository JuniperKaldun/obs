# Сессия 2 — Права доступа

← [[DevOps]] · [[Дорожная карта]]

## Цель

## Разбор реальной строки

`drwxrwxr-x 2 juniperkaldun juniperkaldun 4096 <имя>`

| Поле | Значение | Смысл |
|---|---|---|
| `d` | тип | каталог |
| `rwx` | владелец | читать, писать, входить |
| `rwx` | группа | то же |
| `r-x` | остальные | читать и входить, создавать нельзя |
| `2` | ссылки | каталог + запись в родителе, подкаталогов нет |
| `juniperkaldun` | владелец | |
| `juniperkaldun` | группа | персональная группа пользователя |
| `4096` | размер | у каталогов почти всегда один блок 4 КБ |

В цифрах — **775**. Счётчик ссылок: у `~/devops/lesson1` должно быть `4` (двойка + `notes` + `logs`), у пустого подкаталога — `2`.

## Ловушки

> [!warning] WSL и `/mnt/c`
> На Windows-диске POSIX-права не хранятся: `chmod` молча ничего не меняет, а `ls` показывает `777`. Учиться правам можно только в родной ФС Linux, то есть в `~`.

- Группа с `w` означает, что любой участник группы может создавать и удалять файлы внутри.
- `chmod 777` на конфиг или ключ = любой процесс машины может его перезаписать.

## Материалы сессии

- `ls -l /etc/passwd /etc/shadow` — почему `shadow` не читается обычным пользователем
- `chmod 600`, `644`, `u+x`, `a-w`
- `mkdir … && chmod 700` → `chmod 000` → отказ и на `ls`, и на `cd`
- `sudo chown root:root` → отказ на запись → `chown $USER:$USER`
- `umask` → `022` → файлы `644`, каталоги `755`
