# DevOps — план обучения

> [!abstract] Цель
> С нуля до первого оффера junior DevOps за **12–14 месяцев** при **трёх занятиях в неделю** (~8–9 часов).

## Сейчас в работе

- **Месяц:** 1
- **Тема:** проект месяца — nginx, TLS, бэкапы, ufw
- **Артефакт:** сайт по HTTPS с ПК, рабочий бэкап, закрытый firewall (ноутбук вместо VPS)

> [!tip] Правило этапа
> Этап закрыт только тогда, когда артефакт получается **без подсказок**. Иначе дальше не идём.

## Принципы

1. 30% теории — 70% практики.
2. Фиксированные дни и время. Пропуск больше трёх дней подряд — потеря прогресса.
3. В дни отдыха 10–15 минут: заметки, документация, одно короткое видео.
4. После каждой сессии — конспект на 5–10 строк своими словами.
5. Один сквозной проект вместо десяти учебных.
6. Раз в два месяца — сверка с чек-поинтами ниже.

## Чек-поинты

| Когда | Что должно получаться без подсказок |
|---|---|
| Месяц 2 | Поднять сервер с нуля, nginx, TLS, firewall, бэкапы |
| Месяц 4 | Написать скрипт на Python под реальную задачу |
| Месяц 6 | Собрать приложение в Docker и запустить compose-стек |
| Месяц 8 | Задеплоить по кнопке в CI, без ручных шагов |
| Месяц 10 | Воспроизвести инфраструктуру из кода после полного удаления |
| Месяц 12 | Приложение в кластере, есть мониторинг и алерты |
| Месяц 14 | 40 минут рассказа о проектах + ответы по Linux и сетям |

## Чего не делать на старте

- Учить Kubernetes до Linux и сетей.
- Коллекционировать курсы вместо практики.
- Начинать с service mesh, микросервисов и глубокого Go.
- Строить «идеальную» инфраструктуру вместо рабочей.
